# 4 Marketing
Source: one solo developer's TikTok advice (Oct 2026). Opinions, not facts.

19. **Social media first, ads second.** Post clips weekly from the start of development. Talk about the game everywhere.
20. **Look after the community.** Reply to comments, run events and giveaways, keep a Discord. Set it up before testing.
21. **Ads buy data, not just players.** Without an audience a game almost never takes off on its own. Even a small spend with few players is useful if you act on the data. Set a daily budget you can afford to lose (his range: about $10 to 20 per day).
22. **Ad thumbnails:** make 3 different styles, run them about 24 hours, keep the winning style (aim for 3% or better click-through), restyle the others to match, replace anything under 3%.
23. **Give the game page the same effort as gameplay.** Icon, thumbnails, title, trailer. Compare against 3 top games before publishing.
24. **Decide when to reveal gameplay.** Early reveals bring attention but also copycats. Until then, show progress without the whole idea.
