# 2 Making
Source: one solo developer's TikTok advice (Oct 2026). Opinions, not facts.

8. **Get the feel right first.** Movement, combat and animation must feel smooth. Test on mobile and PC.
9. **Base game before testers:** smoother, faster, more efficient, optimized. Models, VFX and GUI come after.
10. **Sound matters as much as graphics.** Budget time and money for it from the start.
11. **Using AI:**
    - Write the plan first. AI builds from your ideas; it doesn't replace a storyboard and a core loop.
    - Tell the AI to ask you questions about the task, answer them, then ask again.
    - Pick one main tool and learn it deeply, unless you have a large budget.
    - Always read and test AI-written code before trusting it.
