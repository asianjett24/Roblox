# 1 Planning
Source: one solo developer's TikTok advice (Oct 2026). These are his opinions and experience. Terms are in [[Glossary]].

1. **Write a game design document before opening Studio.** Pitch, core loop, systems, progression, map, screens, minimum version. It stops you losing track. Use [[GDD]].
2. **List your skills and plan each gap.** Code, models, UI, sound, VFX, art, marketing. For every weakness, decide: hire, learn, or use AI.
3. **Scope to your time and money.** If the full idea doesn't fit, cut it to the version that does. Pausing a big project for a smaller one is a valid decision.
4. **Build the replayable core first.** If the core loop is fun on repeat with no polish, you have a game. UI, animation and extras come later. The common failure is too many ideas and never finishing.
5. **Study 3 similar successful games.** Their core loop, retention hooks, sound and game page.
6. **Stay solo until release; add people for named tasks only,** with clear instructions on what is right and wrong.
7. **Never accept a too-good offer for your game without waiting and checking.** Scams target new developers.
