# Spearfishing Cove (archived)
A low-poly Roblox spearfishing game: dive into a stepped ocean pit, spear creatures, and bank the catch before the zone's guardian catches you. Zones with guardians, bounties, escape streak, sea index, shop and upgrades, bases with an aquarium.

The game code was removed from this repo on 2026-10-19 to make it a vault only. The last version with the code is commit `219e4a3` in the git history. To get it back into a folder: `git checkout 219e4a3 -- .` (or open that commit on GitHub).
